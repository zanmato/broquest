A cross platform API client

Broquest runs on Linux, macOS and Windows. Collections are folders of TOML files, and requests can run JavaScript before they are sent and after the response arrives.

  • No account or cloud sync
  • Environments and secrets
  • Imports OpenAPI, WSDL and cURL

Request tabs

Each request opens in a tab with its own environment and response.

Scripting

Each request has a pre-request and a post-response script. Before the request is sent, a script can change its URL, headers and body through req. After the response arrives, a script can read its status, headers and body through res.

bro.setEnvVar saves a value, such as a token, to the selected environment. Scripts run in QuickJS with LLRT modules for crypto, Buffer and URL, and scripts written for Bruno's bru API run as well.

The editor checks syntax as you type, completes the API and has recipes for common scripts such as HMAC signatures.

Environments

A collection can have several environments, such as Local, Staging and Production. They are stored in collection.toml.

Reference a variable as {{name}} in the URL, query, path parameters, headers, body and auth. Secret values are masked in the editor and saved to the system keychain.

Response filter

Filter a JSON response with a JSONPath expression in the field under it.

XML responses are formatted, images are shown inline and PDFs open in the system viewer. The Raw tab shows the final URL, the request headers that were sent and the response headers.

Collections

Each request is a TOML file and each group is a folder. A collection can live in the repository of the API it tests, and changes to it show up in diffs and pull requests.

Broquest can also open OpenCollection YAML folders, the format used by Bruno, and save changes back in that format. Support for it is partial.

Auth set on the collection is used by every request that inherits it.

Features

Auth
Basic, Digest, API key, JWT and OAuth2 client credentials, set on a request or on the collection.
Body
JSON, XML, HTML, plain text, URL encoded forms and multipart forms with file uploads.
Import
Create a collection from an OpenAPI spec, grouped by tag, or from a WSDL URL. Paste a cURL command into the URL bar to import it, or copy a request as cURL.
History
Every response is listed in the history with its method, URL, status and time.
Palette
Press Ctrl K (⌘ K on macOS) to open a request by name or run a command.
Layout
Show the response under the request or beside it.
Themes
Comes with Catppuccin Latte, Frappé, Macchiato and Mocha. Theme files in the data directory are reloaded when they change.
Updates
Checks GitHub for new releases and updates itself. This can be turned off in the settings.
